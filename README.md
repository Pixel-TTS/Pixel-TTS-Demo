# Pixel-TTS: Image-based Text Rendering for Robust Text-to-Speech

## Demo Page

This repository contains the demo page and speech samples for **Pixel-TTS**, an image-based text rendering approach for robust text-to-speech synthesis.

The demo includes:

- Speech synthesis comparison between **Text-TTS** and **Pixel-TTS**
- Robustness evaluation with **Unicode noise**
- Robustness evaluation with **L33t Speak**
- Out-of-domain evaluation on **SEED-TTS-EN**, **LJSpeech** and **L2-ARCTIC**
